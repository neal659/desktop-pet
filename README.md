# Desktop pet

The orange pixel creature from the usage window, living on the desktop. It walks
along the top of the taskbar, stops now and then, and blinks.

## Run

```
pythonw desktop_pet.pyw
```

Needs only Python 3 on Windows (tkinter and ctypes come with it).

## Controls

- **Right-click the creature:** close it.

## Network

None. The pet makes no network requests.
